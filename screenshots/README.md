# Product screenshots

Store customer-facing product screenshots here for documentation, sales enablement, and user onboarding.

Recommended captures (suggested filenames):
- `01-dashboard.png` — operational dashboard (health/readiness, recent activity)
- `02-upload-workflow.png` — upload flow and successful ingestion
- `03-extraction-results.png` — extracted signals list with confidence and provenance fields visible
- `04-evidence-review.png` — evidence preview + review action (approve/reject/needs clarification)
- `05-approved-export.png` — approved-only export (JSON/CSV) and download action
- `06-audit-log.png` — audit trail view for key actions (ingest, extract, review, export)
- `07-admin-settings.png` — admin/settings view (configuration snapshot, security settings)

Guidelines:
- Use a consistent window size (e.g., 1440×900) and a consistent theme.
- Avoid secrets (API keys), personal data, or real customer documents.
- Prefer PNG for crisp UI text.
- Capture screens that clearly communicate governance: evidence, review state, and approved-only exports.
